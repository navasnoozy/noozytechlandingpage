# Brand

How the NoOzyTech logo is built and used.

## The idea

The capital O in NoOzyTech is deliberate, and the name puts a small o right beside it. The symbol is just that pair: a small ring next to a big one, standing on one baseline. Something small, done well, growing.

It's drawn from the same typeface as the website, so the logo and the pages read as one piece.

## The parts

| Part | Use | Files |
|---|---|---|
| Wordmark | The main logo: navigation, documents, anywhere there's room | `components/brand/wordmark.tsx`, `public/brand/noozytech-wordmark.svg` (and `-white`) |
| Symbol | Where the wordmark won't fit: favicons, app icons, profile pictures | `components/brand/symbol.tsx`, `public/brand/noozytech-symbol.svg` (and `-white`) |
| App icon | The symbol in a dark rounded tile | `public/brand/noozytech-icon-512.png` (the structured data logo), `app/icon.png`, `app/apple-icon.png`, `app/favicon.ico` |
| Profile picture | Instagram and other profiles, which crop it to a circle | `public/brand/noozytech-avatar-1080.png` |

Use the wordmark or the symbol, never both side by side: the wordmark already contains the oO.

## Construction

- **Wordmark:** Inter at the Display optical size, weight 600, letter spacing −0.02em, with Inter's own kerning, converted to outlines. Inter uses the SIL Open Font License, which allows its outlines in a logo.
- **Symbol:** two true circles on one baseline.
  - The big ring is as tall as Inter's capital O at this weight (1538 font units), with a 250-unit stroke.
  - The small ring is 0.60 of that size, with a 210-unit stroke, 160 units away.
- **Small sizes:** at 32 px and below, icons use a bolder cut, with strokes 1.35 times thicker and less padding. Thin rings vanish at 16 px. A scaled-down large icon is not a good small icon.

## Color

- Monochrome only: ink `#1d1d1f` on light backgrounds, `#f5f5f7` on dark ones. The components use `currentColor`, so they follow the text color around them.
- Never another color, a gradient, a shadow, an outline or a glow. Color belongs to the products ([decision 0008](../decisions/0008-monochrome-brand.md)).

## Space and size

- **Clear space:** keep at least the height of the small o (the wordmark's x-height) empty on every side.
- **Smallest sizes:** the wordmark 72 px wide, the symbol 16 px (with the bolder cut).

## Don't

- Retype the wordmark in a font. Always use the files.
- Change the spelling or the capitals.
- Stretch, rotate, outline or recolor it, or place it on a busy photo.

## Changing the logo

Every file above is generated by `scripts/brand/build.py` from the Inter font. Change the numbers at the top of the script, run it (instructions are in the file), check the results, and commit them. Never edit the generated paths by hand.
