# Decisions

Short records of deliberate choices, so that nobody, person or AI, "fixes" them by accident.

## When to write one

When a choice is hard to reverse, affects several parts of the site, or would look like a mistake to someone who doesn't know the reason.

## How

- Name the file `NNNN-short-title.md`, numbered in order.
- Never renumber or delete a record. If a decision changes, write a new one and mark the old one "Superseded by NNNN".
- Keep it short, using this template:

```markdown
# NNNN: Title

Status: Proposed | Accepted | Superseded by NNNN
Date: YYYY-MM-DD

## Context
What made a decision necessary.

## Decision
What we chose.

## Consequences
What follows from it, good and bad.
```
