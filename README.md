# noozytech.com

The website of NoOzyTech, built with Next.js and hosted on Vercel.

- People: start with [docs/README.md](docs/README.md).
- AI agents: start with [AGENTS.md](AGENTS.md).

## Run it locally

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.

## Before every commit

```bash
pnpm check
```

It runs the linter, the type-checker, the format check and a production build. All four must pass.
